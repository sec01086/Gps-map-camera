# GPS Map Camera — GitHub Pages এ পাবলিশ ও হোম স্ক্রিনে ইনস্টল করার গাইড

## ধাপ ১: GitHub রিপোজিটরি তৈরি করুন
1. https://github.com এ গিয়ে লগইন করুন (অ্যাকাউন্ট না থাকলে ফ্রি একটা তৈরি করুন)।
2. উপরে ডানদিকে **+** আইকনে চেপে **New repository** নির্বাচন করুন।
3. Repository name দিন, যেমন: `gps-map-camera`
4. **Public** নির্বাচিত রাখুন, তারপর **Create repository** চাপুন।

## ধাপ ২: ফাইলগুলো আপলোড করুন
1. নতুন রিপোর পেজে **"uploading an existing file"** লিঙ্কে চাপুন (অথবা Add file → Upload files)।
2. এই ফোল্ডারের সবগুলো ফাইল ও ফোল্ডার (`index.html`, `manifest.json`, `service-worker.js`, `favicon.png`, এবং পুরো `icons` ফোল্ডার) টেনে এনে ছেড়ে দিন (drag & drop) — ফোল্ডার স্ট্রাকচার ঠিক রাখতে পুরো `icons` ফোল্ডারটাই টেনে আনুন।
3. নিচে **Commit changes** চাপুন।

## ধাপ ৩: GitHub Pages চালু করুন
1. রিপোর উপরে **Settings** ট্যাবে যান।
2. বাম পাশে **Pages** এ ক্লিক করুন।
3. **Branch** এর নিচে `main` নির্বাচন করুন, ফোল্ডার `/ (root)` রেখে **Save** চাপুন।
4. ১-২ মিনিট অপেক্ষা করুন। পেজ রিফ্রেশ করলে উপরে একটা লিঙ্ক দেখা যাবে, যেমন:
   `https://your-username.github.io/gps-map-camera/`

এই লিঙ্কটাই আপনার অ্যাপের HTTPS লিঙ্ক — এখন থেকে ক্যামেরা ও লোকেশন পারমিশন ঠিকভাবে কাজ করবে।

## ধাপ ৪: হোম স্ক্রিনে ইনস্টল করুন

### Android (Chrome)
1. উপরের লিঙ্কটি Chrome-এ খুলুন।
2. ডানদিকে ⋮ (তিন ডট) মেনুতে চাপুন → **"Install app"** বা **"Add to Home screen"** নির্বাচন করুন।
   *(অথবা অ্যাপের ভেতরে permission স্ক্রিনে থাকা "📲 হোম স্ক্রিনে ইনস্টল করুন" বাটনেও চাপ দিতে পারবেন — এটি স্বয়ংক্রিয়ভাবে দেখা দেবে)*
3. **Add/Install** চাপুন। এখন অ্যাপটি হোম স্ক্রিনে একটি সাধারণ অ্যাপ আইকনের মতো বসে যাবে এবং ফুল-স্ক্রিনে খুলবে।

### iPhone (Safari)
1. উপরের লিঙ্কটি অবশ্যই **Safari** ব্রাউজারে খুলুন (Chrome/অন্য ব্রাউজারে iOS-এ এই অপশন থাকে না)।
2. নিচের **Share** আইকনে (□ থেকে উপরের দিকে তীর) চাপুন।
3. নিচের দিকে স্ক্রল করে **"Add to Home Screen"** নির্বাচন করুন।
4. নাম ঠিক রেখে **Add** চাপুন।

এরপর হোম স্ক্রিন থেকে খুললে এটি ব্রাউজার অ্যাড্রেসবার ছাড়া, সম্পূর্ণ অ্যাপের মতো খুলবে।

## অফলাইনে চালানো
- প্রথমবার লিঙ্কটি ইন্টারনেটসহ একবার খুলুন (এতে অ্যাপের মূল ফাইলগুলো ডিভাইসে ক্যাশ হয়ে যাবে)।
- এরপর থেকে ইন্টারনেট ছাড়াও হোম স্ক্রিনের আইকনে চেপে অ্যাপ খোলা যাবে (ক্যামেরা কাজ করবে)।
- মানচিত্র অফলাইনে দেখতে চাইলে, অ্যাপের **সেটিংস → অফলাইন মানচিত্র ডাউনলোড** থেকে প্রয়োজনীয় এলাকা আগেই ডাউনলোড করে রাখুন।
- GPS লোকেশন পেতে অবশ্যই ফোনের লোকেশন সার্ভিস (GPS) চালু থাকতে হবে — এটা ইন্টারনেট ছাড়াও কাজ করে, কিন্তু ঠিকানা/নতুন ম্যাপ আনতে ইন্টারনেট লাগবে।

## আপডেট করতে হলে
ভবিষ্যতে ফাইলে কোনো পরিবর্তন করলে, GitHub রিপোতে গিয়ে সেই ফাইলটি (বিশেষত `index.html`) আবার আপলোড/এডিট করে Commit করলেই কিছুক্ষণের মধ্যে লাইভ লিঙ্কে আপডেট চলে আসবে।
